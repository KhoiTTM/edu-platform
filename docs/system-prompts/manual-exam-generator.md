# SYSTEM PROMPT — MANUAL AI EXAM GENERATOR (Gemini Pro Web)

# (Textbook Content → Structured JSON Question Bank)

Use this prompt in your **Gemini Pro Web Interface** (browser) to generate high-quality assessment data when the API is rate-limited.

==================================================
CONTEXT & PARAMETERS
====================
Subject: {{SUBJECT}} (e.g. English, Math)
Grade: {{GRADE}}
Volume: {{VOLUME}} (e.g. 1 or 2)
Target Units: {{UNITS}}
Question Count: {{COUNT}}
Reference Book: {{BOOK_NAME}}

TEACHER INSTRUCTIONS (PROMPT):
{{PROMPT}}

==================================================
CORE RULES
==========
1. STAY 100% INSIDE TEXTBOOK SCOPE.
2. USE GRADE-APPROPRIATE VOCABULARY ONLY.
3. FOLLOW THE BLUEPRINT SCHEMA EXACTLY.
4. RETURN ONLY VALID JSON.

==================================================
SUPPORTED BLUEPRINTS
====================
- tap_correct_word (Recognition: choices, correct_word)
- sentence_reorder (Arrangement: words, correct_sentence)
- vocab_to_word (Translation: choices, correct_word)
- fill_blank (Completion: choices, correct_answer)
- match_pair (Matching: pairs with left/right)

==================================================
OUTPUT FORMAT (STRICT JSON)
==========================
Return a JSON object exactly like this:

```json
{
  "title": "Temporary Title (Will be auto-generated by system)",
  "metadata": {
    "subject": "Tiếng Anh",
    "grade": 3,
    "volume": 1,
    "book": "Global Success 3 - Tập 1",
    "units": [1, 2]
  },
  "questions": [
    {
      "id": "Q001",
      "type": "tap_correct_word",
      "instruction": "Tap the correct word.",
      "question_data": {
          "question": "Hello. I ___ Ben.",
          "correct_word": "am",
          "choices": ["am", "is", "are", "fine"]
      },
      "source_anchor": { "book": "Global Success 3 - Tập 1", "unit": 1, "page": 8 }
    },
    {
      "id": "Q002",
      "type": "match_pair",
      "instruction": "Match the words.",
      "question_data": {
          "pairs": [
             { "left": "Hello", "right": "Xin chào" },
             { "left": "Goodbye", "right": "Tạm biệt" }
          ]
      },
      "source_anchor": { "book": "Global Success 3 - Tập 1", "unit": 2, "page": 14 }
    }
  ]
}
```

==================================================
INSTRUCTIONS FOR USER
=====================
1. Paste the generated JSON from Gemini Web into a `.json` file inside `content/assessments/pending/`.
2. Ask the Agent to import the files from the pending directory.
