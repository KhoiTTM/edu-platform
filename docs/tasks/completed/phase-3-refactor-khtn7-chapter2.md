# Title
Refactor KHTN 7 Chapter 2 Content Seeder & Blueprint Engine

# Goal
Fix critical architecture violations in the Chapter 2 implementation by ensuring semantic concept mapping, decoupling question ingestion from the theory seeder, and implementing robust deterministic generators in the blueprints.

# Background context
The previous implementation of Chapter 2 bypassed the Blueprint engine and injected raw questions into the `question_bank` using lazy concept mappings (e.g., `khtn7-ch2-p33`). According to `architecture-lead.md`, the pipeline must be `Curriculum → Concepts → Blueprints → Deterministic Generation`.

# Files involved
- `scripts/seed-khtn7-chapter2-content.ts` (needs heavy refactor)
- `scripts/generators/khtn7/chapter2-blueprints.ts` (needs generator implementations)

# DB changes
- Upsert specific, semantically named concepts (e.g., `khtn7-phan-tu`, `khtn7-don-chat`, `khtn7-hop-chat`) into the `concepts` table.
- **DO NOT** insert directly into `question_bank` during the theory seeding phase.

# APIs involved
None. Pure DB and Node.js logic.

# Dependencies
Must rely on the curriculum generated by `seed-khtn7-curriculum.ts`.
